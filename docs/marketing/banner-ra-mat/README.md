# Banner ra mắt MapsLibVN

Bộ ảnh ra mắt, PHONG duyệt 25/09/2026. Nền xám than `#232327`, màu nhấn `#a3e635`, font Be Vietnam
Pro và JetBrains Mono, cùng bảng màu với website sau khi đổi nền.

| Tệp | Cỡ | Dùng cho |
|---|---|---|
| `chia-se-1200x630.png` | 1200×630 | bài đăng kèm link trên Facebook, LinkedIn, X |
| `bai-dang-vuong-1080x1080.png` | 1080×1080 | bài đăng ảnh Facebook, Instagram, LinkedIn |
| `story-1080x1920.png` | 1080×1920 | story Facebook, Instagram, Zalo (trống 250 px trên, 340 px dưới cho thanh giao diện) |
| `bia-facebook-1640x624.png` | 1640×624 | ảnh bìa trang Facebook (nội dung chính nằm trong khung giữa, điện thoại cắt hai bên) |
| `bia-x-1500x500.png` | 1500×500 | ảnh bìa X (góc dưới trái để trống cho ảnh đại diện) |

Mọi chữ và số trên ảnh lấy từ mã thật: con số 37–68% từ `soSanh()` trong `apps/site/src/lib/gia.ts`,
gợi ý "nha tho duc ba" từ `apps/site/src/lib/goi-y.ts`, gói dùng thử 2.000 lượt Places. Đổi bảng giá
hay gói dùng thử thì phải làm lại ảnh.

Bản gốc có thể chỉnh sửa nằm trên canvas thiết kế riêng của PHONG trên claude.ai (banner "Banner ra
mắt MapsLibVN"); các tệp PNG ở đây được xuất từ đó ở đúng cỡ 1×.
